🧭 AK4 是什么：盘古竞赛（Pangea Matematiktävling）四年级组，瑞典 PMT。初赛 12 题（1-5⋆），决赛 10 题（1-5⋆）。 每题 5 选 1，答对加分、答错扣少量分、不答 0 分。
⚡ 核心能力：读题 + 运算 + 空间想象 + 模式识别。不考分数运算、代数证明、角度、百分数、概率。
🏆 拿分策略：1-2⋆ 送分题 一道都不能错；3⋆ 稳扎稳打；4-5⋆ 挑强项做；没把握就跳过（避免扣分）。

👨‍👩‍👧 给家长的 5 句话

  1. 读题比运算重要。孩子答错 70% 不是算错，是读错题——"比多"读成"多"、单位没换、问的是和还是差。
  2. 画图是护身符。几何题画图、应用题画线段、逻辑题画表格——不画图就减分。
  3. 陷阱题要练。"农民几岁"（动物数量 ≠ 年龄）是经典陷阱，答案常是 e) 无法解决。
  4. 运算必须 100% 正确。1-2⋆ 送分题错一道，总分就落后 5-7 分。
  5. 没把握就跳过。盘古答错扣少量分（1/4 分），不答 0 分。概率小于 1/5 不要蒙。

🧮 二、基础运算（必学 · 送分最多）

考什么

  • 加减乘除混合运算、运算顺序、速算技巧（凑整、配对、逆运算）
  • 单位换算：长度 (cm/dm/m/km)、重量 (g/kg)、容积 (ml/l)、时间 (秒/分/时)
  • 填符号 / 填数：如 12 __ 3 = 36 填 ×

如何引导

  1. 每天 10 分钟口算（50 道），要求又快又准
  2. 凑整感觉：25×4=100、125×8=1000、99=100−1，熟练后口算 10 以内加减瞬间完成
  3. 单位换算卡片：1 m = 100 cm = 1000 mm、1 km = 1000 m、1 kg = 1000 g（反复背）
  4. 运算顺序口诀：先括号 → 再乘除 → 最后加减；同级从左往右

⚠️ 要注意

  • 瑞典用小数点逗号（1,21 m = 1.21 m）。要让孩子认识这个写法
  • 瑞典单位写法：krona (kr) 克朗、meter (m)、kilogram (kg)。欧洲数字用空格分组（1 234 = 1234）
  • "比 X 少 n" 写成 X−n，不是 n−X——读题时划横线强调

📝 例题 · ⋆ Thomas 身高

Lea 身高 1 米 21 厘米，哥哥 Thomas 比 Lea 矮 23 厘米。Thomas 多高？
  1. 统一单位：1 m 21 cm = 121 cm（必须先换单位）
  2. 121 − 23 = 98 cm
答：98 cm

💼 三、应用题（必学 · 读题是关键）

考什么

  • 和差倍问题、鸡兔同笼变形、简单行程、简单工程、容器、经济（买卖）、年龄
  • 最常见题型：和差问题（如柠檬牛油果共 40 kr，牛油果贵 30 kr，柠檬几 kr？）

如何引导

  1. 读题三遍法：
    • 第 1 遍：找问什么（画问号）
    • 第 2 遍：找已知条件（划线）
    • 第 3 遍：找陷阱（有没有多余信息？单位一样吗？）
  2. 画线段图：和差问题画两条线段，长短对比直观
  3. 列表格：鸡兔同笼类画假设表
  4. 先估后算：答案在选项中大概落哪个范围？排除明显不合理的

🧠 和差问题公式（必背）

两数和 = a + b；两数差 = a − b（a 大）

  • 小的 = (和 − 差) ÷ 2
  • 大的 = (和 + 差) ÷ 2

例：和 40、差 30 → 小 = (40−30)÷2 = 5，大 = (40+30)÷2 = 35。

📝 例题 · ⋆ 柠檬和牛油果（PMT 2021/22 O1 #1）

Kevin 买一个柠檬和一个牛油果，共付 40 克朗。牛油果比柠檬贵 30 克朗。柠檬几克朗？
  1. 和差问题：和 = 40，差 = 30
  2. 柠檬（小的）= (40 − 30) ÷ 2 = 5
答：a) 5 克朗

⚠️ 应用题 3 大陷阱

  1. "农民几岁"类：题目给动物数量、问主人年龄——两者无关 → 答 无法解决
  2. 单位不统一：有 m、有 cm、有 mm 要先换
  3. "比多"≠"多"：A 比 B 多 5，意思是 A = B + 5，不是 A = 5

📏 四、平面几何（必学 · 画图！）

考什么

  • 周长：L 形/凸凹图形的周长（走一圈的边长总和）
  • 图形计数：数三角形、正方形、长方形（分大小分类不漏不重）
  • 阴影面积：割补法、整体减法
  • 图形拼接 / 剪切：能否一刀切拼成正方形

如何引导

  1. 必画图！看到几何题立刻拿草稿纸画出来
  2. L 形周长技巧：L 形的周长 = 外接长方形的周长（凹进去的那段来回抵消）
  3. 图形计数套路：
    • n×n 方格里的正方形数 = 1² + 2² + ... + n²
    • 2×2 方格 = 5 个正方形（要记）、3×3 = 14 个
    • 长方形数 = C(横线数, 2) × C(竖线数, 2)
  4. 阴影面积三法：割（拆成小块）、补（补成规整）、减（整体 − 空白）

📝 例题 · ⋆⋆⋆ 外正方形+两对角线+内嵌小正方形（PMT 2122 决赛类）

大正方形里画两条对角线，再画一个顶点在边中点的小正方形（旋转 45°）。图中有多少个三角形？
  1. 两条对角线把大正方形分 4 个大三角形
  2. 对角线和小正方形相交形成 4 个小三角形
  3. 共 4 + 4 = 8
答：8 个

🧊 五、立体几何（高难度 · 空间想象）

考什么

  • 骰子：对面之和 = 7（1↔6、2↔5、3↔4）
  • 展开图：11 种标准展开图，判断能否折立方体、哪两面相对
  • 三视图：正视 / 左视 / 俯视，正反推
  • 立方体切割 / 涂色：n³ 块分 3 面/2 面/1 面/0 面涂色
  • 堆叠计数：数方块、补成大长方体缺多少

如何引导

  1. 动手搭积木：买一盒磁力片或小木块，让孩子亲手搭 2×2×2、3×3×3，再数三视图
  2. 折纸练展开图：拿硬纸板画 6 格十字，剪下折成立方体，每面标数字，观察相对面
  3. 骰子口诀：对面和 7 不变，一颗骰子所有点数之和 = 1+2+3+4+5+6 = 21；n 颗骰子 = 21n
  4. 立方体切割公式（n×n×n 大立方体 → n³ 小方块）：
    • 3 面涂色（角）：永远 8 个
    • 2 面涂色（棱中间）：12(n−2)
    • 1 面涂色（面中间）：6(n−2)²
    • 0 面涂色（内部）：(n−2)³

⚠️ 立体几何高频坑

  • 骰子对面给 2 问背面，背面 = 7 − 2 = 5，不是直接选 5 的下一个
  • 展开图相对面：排一行 1-2-3 时 1 和 3 对面，不是 1 和 2
  • 堆叠计数：被挡住的后排方块也要算

📝 例题 · ⋆⋆⋆⋆ 立方体最少数

用一些小立方体拼成一个大立方体（不剩）。最少几块？
  1. 拼出来必须是 立方数：1, 8, 27, 64...
  2. 1 块是"大=小"，不算；最小是 8 块（2×2×2）
答：8 块

🧩 六、智力题 / 数字谜（填符号 / 填数）

考什么

  • 算式填符号：如 12 __ 4 __ 3 = 15，判断填什么运算符
  • 算式填数：如 7□9 − 222 = 497，□ 填几
  • 符号代数：★+■−● 由三个等式求值

如何引导

  1. 反推：告诉孩子"看等号右边倒着做"
  2. 试填：选项不多的时候逐个代入
  3. 多方程联立：从简单方程先求出一个变量，代入其他方程

📝 例题 · ⋆⋆ ★+■−● 三方程（PMT 2122 O1 #5）

6+★=14、★−■=5、■·●=6。求 ★+■−●。
  1. 从第 1 式：★ = 14 − 6 = 8
  2. 从第 2 式：■ = 8 − 5 = 3
  3. 从第 3 式：● = 6 ÷ 3 = 2
  4. ★+■−● = 8+3−2 = 9
答：e) 9

🎯 七、计数 / 组合

考什么

  • 排列（有序）：3 本书排一排 = 3×2×1 = 6 种
  • 组合（无序）：5 队循环赛 = C(5,2) = 10 场
  • 书页 / 位数：一本书页码用 264 位，有几页？
  • 排队 / 握手问题

如何引导

  1. 画树状图枚举：数量不大时直接列出来
  2. 加法原理 vs 乘法原理：
    • "或"（分类）→ 加法：A 事件 n 种 + B 事件 m 种 = n+m
    • "再"（分步）→ 乘法：第 1 步 n 种，第 2 步 m 种 → n×m
  3. 组合公式：n 选 2 = n×(n−1)÷2（握手 / 比赛场次常用）
  4. 书页位数：1-9 用 9 位、10-99 用 180 位、100-999 用 2700 位（按三段算）

📝 例题 · ⋆⋆⋆⋆ 一本书用了 264 位数字（PMT 2122 O1 #9）

一本书页码用了 264 个数字。书有几页？
  1. 1-9：9 页 × 1 位 = 9 位
  2. 10-99：90 页 × 2 位 = 180 位（累计 189 位）
  3. 还剩 264 − 189 = 75 位分给 100 以上，每页 3 位 → 75 ÷ 3 = 25 页
  4. 共 99 + 25 = 124 页
答：b) 124

🔁 八、规律 / 数列

考什么

  • 等差数列：相邻差相等。如 2, 5, 8, 11... (d=3)
  • 二阶差：相邻差本身是等差。如 1, 2, 4, 7, 11, 16 (差 1, 2, 3, 4, 5)
  • 三角数：1, 3, 6, 10, 15, 21... = n(n+1)/2
  • 平方数：1, 4, 9, 16, 25... = n²
  • 图形规律：第 n 图的点/边/格子数

如何引导

  1. 看前几项规律：先算差（等差？）→ 算差的差（二阶差？）→ 算比值（等比？）
  2. 熟背 5 大数列：
    • 等差：2, 5, 8, 11... 公差 d
    • 三角数：1, 3, 6, 10, 15... Tₙ = n(n+1)/2
    • 平方数：1, 4, 9, 16... n²
    • 斐波那契：1, 1, 2, 3, 5, 8, 13...
    • 二阶差：1, 2, 4, 7, 11... 差递增
  3. 图形规律：数出前 3-4 图的个数，列成序列再找规律

📝 例题 · ⋆ 点阵第 5 图（PMT 2122 O1 #3）

图 1: 1 点、图 2: 3 点、图 3: 6 点、图 4: 10 点。第 5 图几点？
  1. 序列 1, 3, 6, 10 → 差 2, 3, 4（三角数）
  2. 第 5 图 = 10 + 5 = 15
答：b) 15

🧠 九、逻辑推理

考什么

  • 排序 / 排位推理：几个人按条件排名次
  • 真假话：一句真/几句假，推出事实（AK4 较少，4-5⋆）
  • 陷阱题：问题和条件无关（"农民几岁"）

如何引导

  1. 画表格：横着人，竖着位置，打 ✓/✗
  2. 先定死的：条件中最具体的信息（"X 是第 1"）先定
  3. 排除法：选项 5 个，排除 4 个即可

📝 例题 · ⋆⋆⋆ 6 人赛跑名次（PMT 2122 O1 #7）

Ella 第 3；Saga 在 Lucas 之后、Ronja 之前；Aylin 第 1；Fabian 在 Saga 之后但不最后。第 4 名是谁？
  1. 先定死的：Aylin=1、Ella=3
  2. Lucas < Saga < Ronja，而 2、4、5、6 还空着
  3. Fabian > Saga 且 Fabian ≠ 6
  4. 尝试：Lucas=2、Saga=4、Fabian=5、Ronja=6 全满足 ✓
答：a) Saga

🔢 十、数论 / 数位

考什么

  • 奇偶性：奇+奇=偶、奇×奇=奇
  • 整除：能被 2/3/5/9 整除的特征
  • 位数计数：数字 N 用几位（见"计数"章）
  • 数轴 / 定位：标定一个数在数轴哪里

如何引导

  1. 整除口诀：
    • ÷2：末位是偶数
    • ÷3 或 ÷9：所有位数之和能被 3 或 9 整除
    • ÷5：末位是 0 或 5
    • ÷4：末 2 位数能被 4 整除
  2. 奇偶检验法：答案一定是奇数？偶数？先排除

📝 例题 · ⋆⋆⋆⋆⋆ 四位数末尾 0 抹掉（PMT 2122 O1 #12）

四位数 N 末位是 0，抹掉 0 得三位数 x。N + x = 1903，求 N − x。
  1. N = 10x，所以 N + x = 11x = 1903
  2. 1903 ÷ 11 = 173（整除）→ x = 173，N = 1730
  3. N − x = 1730 − 173 = 1557
答：c) 1557

⏰ 十一、时间 / 日期

考什么

  • 时刻差：从 A 时到 B 时过了多久
  • 周期：每 n 天跑一次步，几号再同时跑
  • 星期几：今天星期三，过 50 天是星期几

如何引导

  1. 60 进制：1 时 = 60 分、1 分 = 60 秒。时间减法要借 60
  2. LCM 最小公倍数：周期题关键
  3. 星期几模 7：过 n 天 = 当前 + (n mod 7) 天

📝 例题 · ⋆⋆⋆⋆ 公车下下趟（PMT 2122 O1 #10）

现在 14:42。上趟公车 5 分钟前发车（但晚了 3 分钟）。下趟 14:50 发。下下趟几点？
  1. 上趟按时刻表 = 14:37（真实发车）− 3 分钟（晚点）= 14:34（应发时刻）
  2. 间隔 = 14:50 − 14:34 = 16 分
  3. 下下趟 = 14:50 + 16 = 15:06
答：e) 15:06

🚫 十三、十大常见错误（照着改）

  1. 不读题就下笔：读 3 遍再动笔
  2. 单位不统一：先全部换成一个单位
  3. "比多"读成"多"：A 比 B 多 5 → A = B+5
  4. 几何不画图：画了图题就解完了一半
  5. 立方体展开图相对面搞错：排一行时 1、3 对面，不是 1、2
  6. 数列只看前 2 项：至少看 3 项再判断
  7. 排序推理不画表格：条件多就一定要画
  8. 陷阱题答成具体数字：仔细想问题和条件有没有必然联系
  9. 蒙题：没把握不如空着（答错扣分）
  10. 检查环节跳过：留 5 分钟逐题过一遍
